## 2. :icon-number: Number System (संख्या पद्धति)

### 2.1 Place value, face value और number names

- **Face value (अंकित मान):** digit स्वयं जितना दिखता है। 7 का face value हमेशा 7।
- **Place value (स्थानीय मान):** digit की position के अनुसार value।
- Indian system: ones, tens, hundreds, thousand, ten thousand, lakh, ten lakh, crore।
- Commas को Indian system में right से 3, फिर 2–2 digits के बाद लगाएँ: 12,34,56,789।
- International system में million और billion की grouping अलग होती है।

| Number | Digit | Place (स्थान) | Place value (स्थानीय मान) | Face value |
|---:|---:|---|---:|---:|
| 4,05,307 | 4 | Lakhs | 4,00,000 | 4 |
| 4,05,307 | 5 | Thousands | 5,000 | 5 |
| 4,05,307 | 3 | Hundreds | 300 | 3 |
| 4,05,307 | 0 | Tens | 0 | 0 |
| 4,05,307 | 7 | Ones | 7 | 7 |

**Expanded form (विस्तारित रूप):**

```text
4,05,307 = 4,00,000 + 5,000 + 300 + 0 + 7
```

::: trap ⚠️ Zero trap (शून्य का जाल)
Zero का face value 0 होता है, लेकिन place-holder के रूप में वह दूसरे digits का place सुरक्षित रखता है। 4,05,307 को 45,307 लिखना सही नहीं है।
:::

### 2.2 Comparing, ordering और estimation

- पहले digits की संख्या compare करें। अधिक digits वाली positive संख्या बड़ी होती है।
- digits की संख्या समान हो तो leftmost digit से comparison शुरू करें।
- Number line पर right side value बड़ी होती है।
- Ascending order (आरोही क्रम) = छोटी से बड़ी।
- Descending order (अवरोही क्रम) = बड़ी से छोटी।
- Estimate (अनुमान) answer की reasonableness check करने में मदद करता है।

**Rounding (निकटतम मान):**

| किस place तक round करना है | किस digit को देखें? |
|---|---|
| Nearest ten (दहाई) | Ones digit |
| Nearest hundred (सैकड़ा) | Tens digit |
| Nearest thousand (हजार) | Hundreds digit |

Rule: देखी गई digit 5 या अधिक हो तो previous place में 1 जोड़ें; 5 से छोटी हो तो previous place unchanged रखें।

```text
4,678 nearest ten     = 4,680
4,678 nearest hundred  = 4,700
4,678 nearest thousand = 5,000
198 × 49 का estimate ≈ 200 × 50 = 10,000
```

### 2.3 Factors, multiples और prime numbers

- **Factor (गुणनखंड):** जो number किसी संख्या को बिना remainder के divide करे।
- **Multiple (गुणज):** किसी number को 1, 2, 3… से multiply करने पर मिलने वाला number।
- हर positive number का factor 1 और स्वयं वह number होता है।
- 1 न prime है, न composite।
- **Prime number (अभाज्य):** exactly two positive factors—1 और स्वयं।
- **Composite number (भाज्य):** two से अधिक factors।
- 2 सबसे छोटी और एकमात्र even prime number है।

```text
Factors of 24 = 1, 2, 3, 4, 6, 8, 12, 24
Multiples of 6 = 6, 12, 18, 24, 30, ...
```

### 2.4 Divisibility tests (विभाज्यता के नियम)

| Divisor | Rule (नियम) | Example |
|---:|---|---|
| 2 | Last digit 0, 2, 4, 6 या 8 | 438 |
| 3 | Digits का sum 3 से divisible | 372: 3+7+2=12 |
| 4 | Last two digits 4 से divisible | 1,316 → 16 |
| 5 | Last digit 0 या 5 | 2,745 |
| 6 | 2 और 3 दोनों से divisible | 342 |
| 8 | Last three digits 8 से divisible | 1,024 → 024 |
| 9 | Digits का sum 9 से divisible | 5,832: sum 18 |
| 10 | Last digit 0 | 4,530 |
| 11 | Alternate digit sums का difference 0 या 11 का multiple | 1,331 |

**ध्यान दें:** 3 और 9 के लिए digit sum देखें; 2, 5 और 10 के लिए last digit महत्वपूर्ण है।

### 2.5 Prime factorisation, HCF और LCM

**Prime factorisation (अभाज्य गुणनखंडन):** किसी number को prime factors के product के रूप में लिखना।

```text
60 = 2 × 2 × 3 × 5 = 2² × 3 × 5
84 = 2 × 2 × 3 × 7 = 2² × 3 × 7
```

- **HCF/GCD (महत्तम समापवर्तक):** common factors में सबसे बड़ा।
- **LCM (लघुत्तम समापवर्त्य):** common multiples में सबसे छोटा positive multiple।
- HCF grouping/sharing problems में useful है।
- LCM repeated events/together-again problems में useful है।

**Prime factor method:**

```text
18 = 2 × 3²
24 = 2³ × 3
HCF = common primes की छोटी powers = 2 × 3 = 6
LCM = सभी primes की बड़ी powers = 2³ × 3² = 72
```

For two positive numbers:

```text
HCF × LCM = Product of the two numbers
```

::: example 🧩 Word-problem clue (शब्द-प्रश्न संकेत)
“सबसे बड़े समान groups/tiles” दिखे तो HCF सोचें। “कब फिर साथ आएगा?” या repeating bells/times दिखे तो LCM सोचें।
:::

### 2.6 Whole numbers और properties

Whole numbers: `0, 1, 2, 3, ...`। इनमें negative numbers और fractions शामिल नहीं होते।

| Property (गुण) | Addition | Multiplication |
|---|---|---|
| Closure (संवृतता) | whole + whole = whole | whole × whole = whole |
| Commutative (क्रमविनिमेय) | a+b=b+a | a×b=b×a |
| Associative (साहचर्य) | (a+b)+c=a+(b+c) | (a×b)×c=a×(b×c) |
| Identity (तत्समक) | 0 | 1 |
| Distributive (वितरण) | — | a×(b+c)=a×b+a×c |

- Subtraction और division whole numbers में हमेशा closed नहीं हैं: 3−5 whole number नहीं है; 5÷2 whole number नहीं है।
- Successor (उत्तरवर्ती) = number + 1।
- Predecessor (पूर्ववर्ती) = number − 1; 0 का whole-number predecessor नहीं होता।

### 2.7 Powers and exponents (घात और घातांक)

```text
2³ = 2 × 2 × 2 = 8
5² = 5 × 5 = 25
```

- Base (आधार) = जिस number को repeat किया जाता है।
- Exponent/power (घातांक) = repeat होने की संख्या।
- `a¹ = a`, `a⁰ = 1` for non-zero `a`।
- Same base multiplication: `aᵐ × aⁿ = aᵐ⁺ⁿ`।
- Same base division: `aᵐ ÷ aⁿ = aᵐ⁻ⁿ` when defined।

### 2.8 Number sense checklist

किसी number question में:

1. Sign positive है या negative?
2. Place value / unit कौन-सी है?
3. Number line पर position क्या है?
4. Estimate से answer reasonable लगता है?
5. Question factor, multiple, HCF या LCM में से क्या पूछ रहा है?

## 3. :icon-number: Integers, Fractions और Rational Numbers (पूर्णांक, भिन्न और परिमेय संख्याएँ)

### 3.1 Integers (पूर्णांक) और number line

Integers में negative numbers, zero और positive numbers आते हैं:

```text
..., −3, −2, −1, 0, 1, 2, 3, ...
```

```figure
type: integer-line-paper2
point: -3
other: 2
caption: number line पर right side वाला integer greater होता है
```

- 0 न positive है, न negative।
- Number line पर right जाने पर value बढ़ती है; left जाने पर घटती है।
- **Absolute value (परम मान):** zero से distance; `|−8| = 8` और `|8| = 8`।
- **Additive inverse (योगात्मक प्रतिलोम):** जिसका sum 0 हो; `−7` का inverse `+7`।
- Opposite integers zero से समान distance पर opposite directions में होते हैं।

### 3.2 Integer operations और sign rules

Number line movement से addition और subtraction समझें:

```text
−6 + 9 = 3       (−6 से 9 steps right)
7 − 12 = −5      (7 से 12 steps left)
```

| Operation | Sign rule |
|---|---|
| Same signs का multiplication/division | Positive |
| Different signs का multiplication/division | Negative |
| Same signs का addition | Magnitudes add, same sign |
| Different signs का addition | Magnitudes subtract, larger magnitude का sign |

```text
(−4) × (−3) = +12
(−24) ÷ 6 = −4
−8 + (−5) = −13
−8 + 5 = −3
```

**Subtraction को addition में बदलें:**

```text
a − b = a + (−b)
7 − (−3) = 7 + 3 = 10
```

::: trap ⚠️ Integer sign trap (चिह्न का जाल)
`−(−3)` का अर्थ `+3` है। Bracket को हटाने से पहले negative sign और अंदर के sign को ध्यान से पढ़ें।
:::

### 3.3 Fractions (भिन्न) का अर्थ

Fraction whole के **equal parts (समान भागों)** में से selected parts बताती है।

- **Numerator (अंश):** selected/count किए गए parts।
- **Denominator (हर):** whole के total equal parts।
- Denominator 0 नहीं हो सकता।

```figure
type: fraction-compare-paper2
a_num: 3
a_den: 4
b_num: 6
b_den: 8
caption: equal wholes में 3/4 और 6/8 equivalent fractions हैं
```

**Types (प्रकार):**

| Type | Meaning | Example |
|---|---|---|
| Proper fraction (समुचित भिन्न) | Numerator < denominator | 3/5 |
| Improper fraction (विषम भिन्न) | Numerator ≥ denominator | 7/5 |
| Mixed number (मिश्रित संख्या) | Whole + proper fraction | 1 2/5 |
| Unit fraction (इकाई भिन्न) | Numerator 1 | 1/8 |
| Equivalent fractions (समतुल्य) | Same value, different form | 3/4=6/8 |

### 3.4 Equivalent fractions और comparison

- Numerator और denominator को same non-zero number से multiply/divide करने पर equivalent fraction मिलती है।

```text
3/4 = 6/8 = 9/12
```

**Comparison rules:**

- Same denominator: larger numerator वाली fraction बड़ी।
- Same numerator: smaller positive denominator वाली fraction बड़ी।
- Different denominators: common denominator, cross multiplication या equal-whole model use करें।

```text
3/4 = 6/8, इसलिए 3/4 > 5/8
```

::: trap ⚠️ Fraction misconception (भिन्न की भ्रान्ति)
`1/3 > 1/2` केवल इसलिए नहीं कि 3 > 2। Whole को equal size मानकर unit parts का size compare करें; thirds, halves से छोटे होते हैं।
:::

### 3.5 Fraction operations

**Addition/subtraction:**

- Like denominators में denominator वही रखें और numerators operate करें।
- Unlike denominators में पहले common denominator बनाएं।

```text
2/7 + 3/7 = 5/7
2/3 + 1/6 = 4/6 + 1/6 = 5/6
5/8 − 1/4 = 5/8 − 2/8 = 3/8
```

**Multiplication:**

```text
3/5 × 10/9 = 30/45 = 2/3
```

Numerator × numerator और denominator × denominator; पहले common factors cancel कर सकते हैं।

**Division:** दूसरे fraction के reciprocal (व्युत्क्रम) से multiply करें।

```text
4/7 ÷ 2/7 = 4/7 × 7/2 = 2
```

### 3.6 Decimals और fractions

- Tenths = `/10`, hundredths = `/100`, thousandths = `/1000`।
- Decimal place value को right से पढ़ें: 0.375 = 3 tenths + 7 hundredths + 5 thousandths।
- Decimal comparison में decimal point align करें।

```text
0.75 = 75/100 = 3/4
0.7 = 0.70, इसलिए 0.7 > 0.65
```

### 3.7 Rational numbers (परिमेय संख्याएँ)

Rational number वह संख्या है जिसे `p/q` के रूप में लिखा जा सके, जहाँ `p` और `q` integers हैं और `q ≠ 0`।

Examples: `3/4`, `−5/2`, `0 = 0/1`, `7 = 7/1`।

- हर integer rational number है।
- Rational numbers positive, negative या zero हो सकते हैं।
- Number line पर rational numbers को fractions में divide करके locate कर सकते हैं।
- Equivalent forms अलग दिख सकती हैं पर same value हो सकती है।

### 3.8 Fraction problem protocol (भिन्न प्रश्न क्रम)

```text
Whole same है? → numerator/denominator identify करें
→ equivalent/common denominator बनाएं → operation करें
→ simplify करें → estimate से check करें
```

## 4. :icon-formula: Ratio, Proportion और Unitary Method (अनुपात, समानुपात और इकाई विधि)

### 4.1 Ratio (अनुपात)

Ratio दो **same-kind quantities** की comparison है। Units समान हों या पहले convert करें।

```text
12 cm : 18 cm = 12 : 18 = 2 : 3
```

```figure
type: ratio-strip-paper2
a: 2
b: 3
caption: equal-sized units का उपयोग करके 2:3 ratio दिखाई गई है
```

- Ratio order-sensitive है: boys:girls और girls:boys अलग हो सकते हैं।
- Ratio को simplest form में लाने के लिए दोनों terms को same common factor से divide करें।
- Equivalent ratio में दोनों terms को same non-zero factor से multiply/divide करें।

```text
4 : 7 = 8 : 14 = 12 : 21
```

### 4.2 Ratio, fraction और rate में अन्तर

| Concept | अर्थ | Example |
|---|---|---|
| Ratio (अनुपात) | दो quantities की comparison | 2 red : 3 blue |
| Fraction (भिन्न) | whole का selected part | 2/5 marbles red |
| Rate (दर) | अलग units की comparison | ₹60 per 3 pens |
| Percentage (प्रतिशत) | per hundred comparison | 25/100 = 25% |

### 4.3 Proportion (समानुपात)

जब दो ratios equivalent हों, तो proportion बनता है:

```text
2 : 3 = 8 : 12
या 2/3 = 8/12
```

यदि `a/b = c/d`, तो cross multiplication से `ad = bc`।

```text
3/4 = x/20
4x = 60, इसलिए x = 15
```

### 4.4 Unitary method (इकाई विधि)

पहले 1 unit का value, फिर required units का value:

```text
6 pens = ₹48
1 pen = ₹48 ÷ 6 = ₹8
8 pens = 8 × ₹8 = ₹64
```

### 4.5 Direct और inverse proportion (प्रत्यक्ष और व्युत्क्रमानुपात)

- **Direct proportion:** एक quantity factor से बढ़े तो दूसरी भी उसी factor से बढ़ती है; total cost और identical items की संख्या इसका example है।
- **Inverse proportion:** एक quantity बढ़ने पर दूसरी घटती है, जैसे fixed work में workers और time का ideal relation। Context और assumptions जाँचें।

### 4.6 Sharing और scale problems

**Ratio में amount बाँटना:**

```text
₹360 को 2:3 में बाँटना
Total parts = 5
One part = ₹360 ÷ 5 = ₹72
Shares = ₹144 और ₹216
```

**Map scale:**

```text
1 cm = 5 km
7 cm = 7 × 5 = 35 km
```

::: remember ✔ Ratio rule (अनुपात नियम)
Ratio में “दोनों terms को same factor” से बदलना आवश्यक है। केवल दोनों numbers बढ़ा देने से equivalent ratio नहीं बनती।
:::

### 4.7 Ratio problem protocol

1. Quantities same units में हैं?
2. Ratio का order क्या है?
3. Simplest form चाहिए या actual values?
4. Total parts या one-unit value क्या होगा?
5. Answer को original context में check करें।

## 5. :icon-calc: Algebra (बीजगणित)

### 5.1 Algebraic language (बीजगणितीय भाषा)

Algebra symbols की मदद से unknown quantities और general relationships को represent करता है।

| Term | Hindi meaning | Example |
|---|---|---|
| Variable (चर) | बदलने वाला/अज्ञात मान | x, y, a |
| Constant (अचर) | fixed value | 5, −2 |
| Coefficient (गुणांक) | variable का numerical factor | 3 in 3x |
| Term (पद) | expression का भाग | 3x, −5, y² |
| Expression (व्यंजक) | terms का combination, equality नहीं | 2x+3 |
| Equation (समीकरण) | बराबर sign वाला statement | 2x+3=11 |

**Common translations:**

```text
5 more than x      → x + 5
5 less than x      → x − 5
5 times x          → 5x
x divided by 5     → x/5
three less than 2x → 2x − 3
```

::: trap ⚠️ Language trap (भाषा का जाल)
“5 less than x” = `x−5`, लेकिन “5 less than twice x” = `2x−5`। Sentence का order ध्यान से पढ़ें।
:::

### 5.2 Like और unlike terms

- Like terms का variable part और exponent same होता है: `3x` और `−5x`।
- Unlike terms: `3x` और `3y`, या `x` और `x²`।
- केवल like terms को combine कर सकते हैं।

```text
3x + 5x − 2 = 8x − 2
4a + 3b को 7ab नहीं लिख सकते
```

### 5.3 Simplification और substitution

- Brackets खोलते समय distributive property use करें: `a(b+c)=ab+ac`।
- Variable की value दी हो तो substitute करें।

```text
If a = 4, then 2a + 3 = 2(4) + 3 = 11
2(3x + 1) = 6x + 2
```

### 5.4 Algebraic identities (बीजगणितीय सर्वसमिकाएँ)

Identities हर permissible value के लिए true रहती हैं:

```text
(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²
```

**Example:**

```text
49² = (50−1)² = 2500 − 100 + 1 = 2401
```

Identity को केवल formula की तरह नहीं, area model या expansion से समझना बेहतर है।

### 5.5 Linear equations (रैखिक समीकरण)

Equation balance की तरह सोचें—दोनों sides पर same operation करें।

```figure
type: algebra-balance-paper2
value: 4
constant: 3
caption: equation में दोनों sides पर same operation करने से balance बना रहता है
```

```text
x + 7 = 15
x + 7 − 7 = 15 − 7
x = 8

2x + 5 = 17
2x = 12
x = 6
```

**Verification (जाँच):** प्राप्त value को original equation में substitute करें।

```text
2(6) + 5 = 17  ✓
```

### 5.6 Algebraic patterns और generalisation

Pattern में rule पहचानकर general term लिखें:

```text
3, 6, 9, 12, ...  → nth term = 3n
```

- Position number और term में relation table बनाकर देखें।
- केवल next term बताना पर्याप्त नहीं; “rule कैसे मिला?” explain करें।
- Generalisation (सामान्यीकरण) algebraic thinking का important हिस्सा है।

### 5.7 Formula और variable sense

Formula में हर symbol का meaning और unit समझें:

```text
Perimeter of rectangle = 2(l+b)
Area of rectangle       = l×b
```

अगर `l=12 cm` और `b=7 cm`, तो perimeter `38 cm` होगा; unit answer में अवश्य दें।

### 5.8 Algebra error checklist

| Error | Possible reason | Better response |
|---|---|---|
| `3x+2=5x` | unlike terms combine करना | Terms और variable parts sort कराएँ |
| `2(x+3)=2x+3` | distributive property अधूरी | Area/arrays से 2×3 भी दिखाएँ |
| `x+3=7` में x=10 | operation direction confusion | Balance model और inverse operation |
| `2x+3=11` में 3 केवल एक side से हटाना | equality का अर्थ unclear | दोनों sides पर same operation |
| Pattern का next term सही, rule नहीं | generalisation का अभाव | position table और explanation |

## 6. :icon-target: Basic Geometry और Angles (मूल ज्यामिति और कोण)

### 6.1 Basic geometrical ideas

| Idea | Hindi meaning | पहचान |
|---|---|---|
| Point (बिंदु) | exact location | कोई length नहीं |
| Line (रेखा) | दोनों directions में endless | कोई endpoint नहीं |
| Line segment (रेखाखंड) | line का सीमित भाग | दो endpoints |
| Ray (किरण) | एक endpoint से एक direction | एक endpoint |
| Parallel lines (समांतर रेखाएँ) | कभी meet नहीं करतीं | same plane में constant distance |
| Intersecting lines (प्रतिच्छेदी) | एक point पर मिलती हैं | common point |
| Perpendicular lines (लम्बवत) | right angle पर मिलती हैं | 90° |

### 6.2 Angles (कोण)

Angle दो rays का common endpoint से बनता है।

| Angle | Measure (माप) |
|---|---:|
| Zero angle (शून्य कोण) | 0° |
| Acute angle (न्यून कोण) | 0° से बड़ा, 90° से छोटा |
| Right angle (समकोण) | 90° |
| Obtuse angle (अधिक कोण) | 90° से बड़ा, 180° से छोटा |
| Straight angle (सरल कोण) | 180° |
| Reflex angle (प्रतिवर्ती कोण) | 180° से बड़ा, 360° से छोटा |
| Complete angle (पूर्ण कोण) | 360° |

**Angle relationships:**

- Complementary angles का sum 90°।
- Supplementary angles का sum 180°।
- Linear pair का sum 180°।
- Vertically opposite angles equal होते हैं।
- एक point के चारों ओर angles का sum 360°।

### 6.3 Parallel lines और transversal

```figure
type: parallel-lines-paper2
caption: parallel lines को transversal काटे तो corresponding और alternate angle relationships बनते हैं
```

जब transversal दो parallel lines को काटती है:

- Corresponding angles equal।
- Alternate interior angles equal।
- Same-side interior angles supplementary (sum 180°)।

**Example:** Same-side interior में एक angle 65° हो तो दूसरा `180°−65°=115°`।

### 6.4 Triangle (त्रिभुज)

- तीन sides, तीन vertices और तीन interior angles।
- Interior angles का sum `180°`।
- Exterior angle = दो opposite interior angles का sum।
- Triangle inequality: किसी भी दो sides का sum तीसरी side से बड़ा होना चाहिए।

**Sides के आधार पर:**

| Triangle | पहचान |
|---|---|
| Scalene (विषमबाहु) | कोई sides equal नहीं |
| Isosceles (समद्विबाहु) | दो sides equal; opposite angles equal |
| Equilateral (समभुज) | तीनों sides equal; हर angle 60° |

**Angles के आधार पर:** acute, right-angled और obtuse triangle।

### 6.5 Congruence और similarity

- **Congruent figures (सर्वांगसम आकृतियाँ):** same shape और same size; superpose करने पर match।
- Triangle congruence criteria: SSS, SAS, ASA/AAS (जहाँ applicable)।
- **Similar figures (समरूप आकृतियाँ):** same shape, size अलग हो सकता है; corresponding angles equal और sides proportional।
- Congruence को similarity का stronger condition समझें।

### 6.6 Quadrilaterals (चतुर्भुज)

- चार sides, चार vertices और interior angle sum `360°`।
- Diagonal opposite vertices को join करता है।

```figure
type: quadrilateral-diagonals-paper2
caption: AC और BD quadrilateral के diagonals हैं; diagonal opposite vertices को जोड़ता है
```

| Shape | मुख्य properties |
|---|---|
| Parallelogram (समांतर चतुर्भुज) | Opposite sides parallel और equal; diagonals bisect each other |
| Rectangle (आयत) | चार right angles; opposite sides equal; diagonals equal |
| Rhombus (समचतुर्भुज) | चार equal sides; diagonals perpendicular bisectors |
| Square (वर्ग) | चार equal sides और चार right angles; rectangle + rhombus |
| Trapezium (समलम्ब) | सामान्यतः एक pair parallel sides |
| Kite (पतंगाकार) | दो-दो adjacent sides equal |

::: remember ✔ Classification rule (वर्गीकरण नियम)
आकृति का नाम देखकर नहीं, properties देखकर classify करें। हर square rectangle है, पर हर rectangle square नहीं।
:::

### 6.7 Polygons (बहुभुज)

- Closed plane figure made of line segments।
- Triangle, quadrilateral, pentagon, hexagon आदि।
- `n`-sided polygon के interior angle sum: `(n−2)×180°`।
- Diagonals की संख्या: `n(n−3)/2`।

```text
Pentagon angle sum = (5−2)×180° = 540°
Pentagon diagonals = 5(5−3)/2 = 5
```

### 6.8 Circle (वृत्त) vocabulary

- Centre (केन्द्र), radius (त्रिज्या), diameter (व्यास), chord (जीवा), arc (चाप), circumference (परिधि)।
- Diameter = `2 × radius`।
- Centre से गुजरने वाली chord diameter होती है और longest chord होती है।
- Circle में line of symmetry अनेक हो सकती हैं।

## 7. :icon-steps: Symmetry, Coordinates और Spatial Understanding (सममिति, निर्देशांक और स्थानिक समझ)

### 7.1 Line symmetry और reflection

- **Line of symmetry (सममिति रेखा):** fold/reflection करने पर दोनों halves match करें।
- Square की 4 lines of symmetry।
- Non-square rectangle की 2।
- Equilateral triangle की 3।
- Circle में infinitely many lines of symmetry।
- Reflection में shape का size same रहता है, orientation mirror की तरह बदल सकती है।

**Reflection language:** left/right, above/below, mirror line और equal distance पर ध्यान दें।

### 7.2 Rotational symmetry

Figure को centre के around turn करने पर यदि वह original से match करे तो rotational symmetry है।

- Square का order 4।
- Equilateral triangle का order 3।
- Rectangle (जो square नहीं) का order 2।
- हर shape का 360° turn trivial रूप से match होता है; order में full turns की संख्या गिनी जाती है।

### 7.3 Coordinate plane (निर्देशांक तल)

Coordinate plane में horizontal **x-axis** और vertical **y-axis** होते हैं।

```figure
type: coordinate-grid-paper2
caption: ordered pair में पहले x-coordinate, फिर y-coordinate पढ़ें
```

- Origin = `(0,0)`।
- Ordered pair = `(x,y)`; पहले horizontal movement, फिर vertical movement।
- Positive x right, negative x left।
- Positive y ऊपर, negative y नीचे।
- Quadrants में signs बदलते हैं: I `(+,+)`, II `(-,+)`, III `(-,-)`, IV `(+,-)`।

**Common trap:** `(2,3)` और `(3,2)` same point नहीं हैं।

### 7.4 Spatial reasoning

Geometry में केवल names याद करना नहीं, बल्कि:

- turn और direction;
- position और distance;
- 2-D से 3-D visualisation;
- nets और views;
- movement, reflection और rotation;
- diagram को अलग orientation में पहचानना;

भी शामिल है।

## 8. :icon-ruler: Construction (ज्यामितीय रचना)

### 8.1 Instruments और उनका काम

| Instrument | Use (उपयोग) |
|---|---|
| Straight edge/ruler (सीधी पट्टी) | line/segment draw करना और length mark करना |
| Scale (मापक) | length measure और mark करना |
| Protractor (कोणमापी) | angle measure/draw करना |
| Compass (परकार) | equal radius arcs और distance transfer करना |
| Pencil और eraser | accurate construction और light arcs |

**Construction में accuracy:** clear points, thin arcs, labels और final lines रखें; rough freehand को final construction न मानें।

### 8.2 Line segment copy करना

1. Given segment की length compass से लें।
2. New ray/line पर desired starting point रखें।
3. Same radius का arc draw करके endpoint mark करें।
4. Segment join और label करें।

### 8.3 Perpendicular bisector (लम्ब समद्विभाजक)

Given segment `AB` के दोनों endpoints से equal radius (जो half से अधिक हो) के arcs ऊपर और नीचे draw करें। Arcs के intersections join करें। यह line:

- `AB` को 90° पर काटती है;
- segment को two equal parts में divide करती है;
- `AB` के हर point से equal distance वाले points का locus है।

### 8.4 Angle bisector (कोण समद्विभाजक)

1. Vertex से arc draw करें जो दोनों arms को cut करे।
2. उन cut points से same radius के arcs draw करें।
3. New intersection को vertex से join करें।
4. दोनों angles equal होंगे।

### 8.5 Standard angle constructions

- 60°: equilateral-triangle arcs से।
- 90°: perpendicular construction से।
- 120°: 60° का supplement या repeated compass arc से।
- Protractor से angle draw करते समय baseline, centre mark और correct scale (inner/outer) देखें।

### 8.6 Triangle construction

```figure
type: triangle-construction-paper2
caption: base draw करें, endpoints से arcs intersect कराएँ, फिर third vertex join करें
```

**SSS (तीन sides दी हों):**

1. एक side को base draw करें।
2. Base के दोनों endpoints से बाकी दो lengths के arcs draw करें।
3. Arc intersection third vertex होगा।
4. Vertex को दोनों endpoints से join करें।

**SAS (दो sides और included angle):**

1. Given base/side draw करें।
2. Included angle construct करें।
3. उस ray पर second side length mark करें।
4. Remaining points join करें।

**ASA/AAS:** Given angles और side की position ध्यान से रखें; angle sum और triangle inequality से construction possible है या नहीं, check करें।

::: trap ⚠️ Construction trap (रचना का जाल)
Compass की opening बदलने से equal-length condition टूट जाती है। Arc draw करते समय radius को बिना कारण न बदलें।
:::

### 8.7 Construction answer checklist

- Instrument का काम सही चुना?
- Given measure को correctly transfer किया?
- Arc intersections visible हैं?
- Labels और units हैं?
- Final figure required property satisfy करती है?

## 9. :icon-calc: 2-D/3-D Shapes और Nets (समतल/ठोस आकृतियाँ और जाल)

### 9.1 2-D और 3-D में अन्तर

| 2-D (समतल) | 3-D (ठोस) |
|---|---|
| Length और breadth | Length, breadth और height/depth |
| Area और perimeter | Surface area और volume |
| Triangle, rectangle, circle | Cube, cuboid, cylinder, cone, sphere |
| Flat drawing/region | Space occupy करता है |

### 9.2 Solids (ठोस आकृतियाँ)

| Solid | Faces/surfaces | Edges | Vertices |
|---|---:|---:|---:|
| Cube (घन) | 6 square faces | 12 | 8 |
| Cuboid (घनाभ) | 6 rectangular faces | 12 | 8 |
| Cylinder (बेलन) | 2 circular faces + curved surface | 2 curved edges | 0 |
| Cone (शंकु) | 1 circular face + curved surface | 1 curved edge | 1 |
| Sphere (गोला) | 1 curved surface | 0 | 0 |
| Triangular prism (त्रिभुजीय प्रिज्म) | 5 faces | 9 | 6 |

- Face flat surface हो सकता है; cylinder/sphere में curved surface भी होती है।
- Edge दो faces/surfaces की meeting boundary है।
- Vertex corner/point of meeting है।
- Convex polyhedra के लिए Euler relation: `F − E + V = 2`।

### 9.3 Nets (जाल)

```figure
type: cuboid-net-paper2
caption: cuboid net में छह rectangular faces fold होकर solid बनाते हैं
```

Net एक 2-D arrangement है जो fold होकर 3-D solid बना सकता है। Valid net में:

- सभी required faces की संख्या हो;
- faces सही edges से connected हों;
- fold करने पर faces overlap न करें;
- solid की dimensions compatible हों।

Cube net में 6 congruent squares होते हैं, लेकिन हर छह-square arrangement valid cube net नहीं होती।

### 9.4 Views और visualisation

Solid को different directions से देखने पर top/front/side views अलग हो सकते हैं। Paper II questions में rotation, hidden faces और net folding के लिए rough sketch बनाना helpful है।

## 10. :icon-ruler: Mensuration (क्षेत्रमिति): Perimeter, Area और Volume

### 10.1 Units और dimensional sense

| Quantity | Units |
|---|---|
| Length/perimeter | cm, m, km (linear units) |
| Area | cm², m² (square units) |
| Volume | cm³, m³ (cubic units) |
| Capacity | mL, L |
| Mass/weight | g, kg |

Conversions:

```text
1 m = 100 cm
1 m² = 10,000 cm²
1 m³ = 1,000,000 cm³
1 kg = 1000 g
1 L = 1000 mL = 1000 cm³ (for water-capacity relation)
```

::: trap ⚠️ Unit trap (इकाई का जाल)
Length conversion को square/volume में सीधे copy न करें। `1 m=100 cm`, लेकिन `1 m²=100×100=10,000 cm²`।
:::

### 10.2 Perimeter (परिमाप)

Perimeter boundary की total length है।

```text
Rectangle: P = 2(l+b)
Square:    P = 4s
Triangle:  P = a+b+c
Regular polygon: P = number of sides × side length
```

### 10.3 Area (क्षेत्रफल)

Area किसी flat region के अंदर covered surface है। Unit squares से पहले meaning बनाएं, formula बाद में।

```figure
type: area-grid-paper2
cols: 6
rows: 4
caption: unit squares count करके area को length × breadth से connect करें
```

| Shape | Area |
|---|---|
| Rectangle | `l × b` |
| Square | `s²` |
| Triangle | `1/2 × base × corresponding height` |
| Parallelogram | `base × corresponding height` |
| Trapezium | `1/2 × (sum of parallel sides) × height` |
| Circle | `πr²` |

**Important:** Triangle/parallelogram में height corresponding base पर perpendicular distance है; slant side को automatically height न मानें।

### 10.4 Circumference और circle

```text
Diameter d = 2r
Circumference = 2πr = πd
Area = πr²
```

`π` का approximate value `22/7` या `3.14` question के अनुसार लें।

### 10.5 Volume और surface area

```text
Cuboid volume = l×b×h
Cube volume   = s³
Cuboid total surface area = 2(lb + bh + hl)
Cube total surface area   = 6s²
```

- Volume space occupied amount है।
- Capacity container कितना hold कर सकता है।
- Same numerical value की units अलग meaning देती हैं: `24 cm`, `24 cm²`, `24 cm³` एक जैसी quantities नहीं हैं।

### 10.6 Scaling और formula application

- Rectangle की length और breadth दोनों double हों तो area 4 times होगा।
- Square की side double होने पर perimeter 2 times, area 4 times।
- Cube की side double होने पर volume 8 times।
- Formula apply करने से पहले shape, given measure, corresponding height और unit देखें।

### 10.7 Mensuration worked examples

```text
Rectangle l=12 cm, b=7 cm
P = 2(12+7) = 38 cm
A = 12×7 = 84 cm²

Triangle base=10 cm, height=6 cm
A = 1/2×10×6 = 30 cm²

Cuboid 5 cm×4 cm×3 cm
V = 5×4×3 = 60 cm³
```

### 10.8 Perimeter vs area vs volume

| Question clue | Quantity |
|---|---|
| Boundary/fencing/ribbon around | Perimeter |
| Floor/paint/cover/tiles inside | Area |
| Space occupied/filling a box | Volume |
| Container कितना hold करता है | Capacity |

## 11. :icon-chart: Data Handling (आँकड़ा प्रबंधन)

### 11.1 Data और variable

- **Data (आँकड़े):** collected facts/observations।
- **Variable (चर):** वह feature जिसे count/measure किया जा रहा है।
- **Frequency (आवृत्ति):** किसी value/category के आने की संख्या।
- पहले clear question और data categories तय करें; फिर collect, organise, represent और interpret करें।

### 11.2 Tally और frequency table

- Key/scale पढ़ना आवश्यक है।
- Half symbol का अर्थ तभी लें जब key अनुमति दे।
- Title, categories, key और question को साथ पढ़ें।

### 11.4 Bar graph और double bar graph

- Bars की equal width और gaps हों।
- Categories अलग और scale स्पष्ट हो।



### 11.5 Mean, median, mode और range

| Median (मध्यका) | Ordered list का middle value | 3 |
| Mode (बहुलक) | Most frequent value | 3 |
| Range (परास) | Maximum − minimum | 8−2 = 6 |

- Median निकालने से पहले data को order करें।
- Even number of values में middle two का average median होता है।
- Mode एक से अधिक भी हो सकता है; कभी कोई mode नहीं होता।
- Outlier mean को strongly influence कर सकता है।

### 11.6 Probability का प्रारम्भिक sense

Probability किसी event के chance को बताती है:

```text
Impossible event = 0
Certain event   = 1
0 ≤ probability ≤ 1
```

Equally likely outcomes में:

```text
P(event) = favourable outcomes / total equally likely outcomes
```

Data और probability questions में sample space, labels और assumptions ध्यान से पढ़ें।

### 11.7 Misleading graphs

- Truncated vertical axis छोटे difference को बहुत बड़ा दिखा सकती है।
- Unequal scale, missing labels और 3-D decoration interpretation को mislead कर सकते हैं।
- Graph देखकर conclusion से पहले “क्या scale और units fair हैं?” पूछें।

## 12. :icon-target: Problem-Solving Protocol (समस्या-समाधान क्रम)

Paper II content questions में यह five-step ladder useful है:

```text
Read → Represent → Relate → Resolve → Review
```

1. **Read (पढ़ें):** question में quantities, signs, units और condition पहचानें।
2. **Represent (दिखाएँ):** number line, strip, table, balance, diagram या graph बनाएं।
3. **Relate (सम्बन्ध):** कौन-सा operation/formula/property लागू है?
4. **Resolve (हल करें):** steps लिखें, units रखें और calculation करें।
5. **Review (जाँचें):** estimate, substitution, graph scale या context से answer check करें।

### High-frequency content traps

| Trap | सही जाँच |
|---|---|
| Negative numbers | Number line और sign |
| Fraction comparison | Equal whole और unit-part size |
| Ratio | Same factor और order |
| Equation | दोनों sides पर same operation |
| Angle | Relationship: 90°, 180°, 360° |
| Construction | Instrument और unchanged radius |
| Area/perimeter | Inside vs boundary और units |
| Volume | तीन dimensions और cubic units |
| Graph | Title, scale, labels और key |
| Coordinate | पहले x, फिर y |

## 13. :icon-brain: Nature of Mathematics और Logical Thinking (गणित की प्रकृति और तार्किक सोच)

Mathematics केवल formulas या fast calculation नहीं है। यह:

- patterns (प्रतिरूप);
- relationships (सम्बन्ध);
- reasoning (तर्क);
- representation (निरूपण);
- estimation (अनुमान);
- problem-solving (समस्या-समाधान);
- communication (संचार);
- justification/proof (औचित्य/प्रमाण);

का subject है।

### Logical-thinking classroom

Learners को:

- conjecture (अनुमानित कथन) बनाना;
- examples और counter-examples देखना;
- classify और compare करना;
- “क्यों?” और “कैसे जानते हो?” explain करना;
- pattern test और generalise करना;
- answer की reasonableness check करना;

चाहिए।

::: example 🧩 Reasoning task (तर्क कार्य)
“Area 24 cm² वाले सभी possible rectangles खोजो और बताओ कि तुम्हें कैसे पता कि list complete है।” यह केवल formula लगाने से अधिक mathematical reasoning मांगता है।
:::

### Myth vs Fact (भ्रान्ति बनाम तथ्य)

| Myth (भ्रान्ति) | Fact (तथ्य) |
|---|---|
| Fast calculation ही अच्छा Mathematics है। | Speed के साथ meaning, strategy और accuracy भी जरूरी हैं। |
| हर problem का केवल एक valid method है। | कई logically valid methods हो सकते हैं। |
| Error का मतलब learner weak है। | Error current reasoning का evidence हो सकता है। |
| Diagram छोटे बच्चों के लिए ही है। | Diagram Paper II में abstract relationships को visible बनाता है। |
| Formula याद है तो concept समझ गया। | Formula select, apply और justify भी करना होता है। |

## 14. :icon-steps: Children’s Strategies और Constructivist Mathematics (बच्चों की रणनीतियाँ और रचनावादी गणित)

### 14.1 Learner as meaning-maker

Learner prior knowledge, language, concrete experience और peer discussion के आधार पर mathematical meaning construct करता है। Teacher का काम केवल method dictate करना नहीं, बल्कि thinking को visible बनाना है।

```figure
type: strategy-ctet
caption: अलग strategies को explain और compare करने से mathematical connections बनते हैं
```

### 14.2 Multiple strategies

एक ही answer के लिए अलग methods हो सकते हैं:

```text
48 + 27 = (40+20) + (8+7) = 75
48 + 27 = 48 + 30 − 3 = 75
```

Teacher को पूछना चाहिए:

- “तुमने यह कैसे किया?”
- “क्या तुम इसे diagram/table से दिखा सकते हो?”
- “कौन-सा method इस context में efficient है?”
- “क्या तुम्हारा answer estimate से reasonable है?”

### 14.3 Concrete–Representational–Abstract (CRA)

```text
Concrete objects/actions → Pictures/diagrams/tables → Symbols/formulas
```

Paper II में concrete models को suddenly छोड़ना जरूरी नहीं है। Algebra tiles, counters, fraction strips, geoboard, grid paper, measuring tools और balance model abstract reasoning का bridge बन सकते हैं।

### 14.4 Productive discussion

Mathematical discourse में learners:

- अपनी method explain करें;
- दूसरे method को ध्यान से सुनें;
- agree/disagree with reason करें;
- representation बदलकर देखें;
- evidence से conclusion revise करें।

Teacher “right answer” के साथ reasoning और communication को भी assess करे।

### 14.5 Scaffolding और gradual independence

- Prompt, worked example, visual cue, vocabulary या partial step दें।
- Learner की competence बढ़े तो prompts fade करें।
- Teacher problem खुद solve करके learner की agency न छीनें।
- Independent transfer task से देखें कि support के बाद concept use हो रहा है या नहीं।

### 14.6 Errors as learning evidence

Wrong answer पर पहले strategy पूछें:

```text
Answer देखें → “कैसे किया?” पूछें → pattern पहचानें
→ misconception diagnose करें → representation/support दें → fresh task से re-check करें
```

## 16. :icon-book: Language of Mathematics (गणित की भाषा)

### 16.1 Mathematical language की विशेषता

Mathematics में words, symbols, diagrams, tables, graphs और precise sentences साथ काम करते हैं।

| Word | Everyday meaning | Mathematical meaning |
|---|---|---|
| Difference | अन्तर | subtraction का result भी |
| Product | वस्तु/परिणाम | multiplication का result |
| Table | मेज | data table या multiplication table |
| Volume | आवाज़ की loudness | space occupied/capacity |
| Mean | मतलब | average |
| Odd | अजीब | विषम संख्या |
| Similar | सामान्य रूप से alike | same shape, proportional sides |
| At least | कम से कम | value ≥ given number |

### 16.2 Word problems पढ़ने की strategy

1. Situation को अपने words में बोलें।
2. Given quantities और units underline करें।
3. Relationship identify करें—combine, compare, scale, share, change या measure।
4. Diagram/table/number line बनाएं।
5. Operation/formula चुनें और answer sentence लिखें।

### 16.3 Multilingual classroom

- Home language को concept bridge की तरह use करें।
- Bilingual word wall बनाएं: factor–गुणनखंड, quotient–भागफल, parallel–समांतर।
- Learner को oral, written, diagrammatic और symbolic explanation के विकल्प दें।
- Language barrier और mathematical concept gap को अलग diagnose करें।
- School language सीखते हुए mathematical reasoning को suppress न करें।

### 16.4 Mathematical discourse prompts

- “तुमने कौन-सा representation चुना और क्यों?”
- “क्या कोई दूसरा तरीका है?”
- “यह answer reasonable कैसे है?”
- “कौन-सी information आवश्यक है?”
- “यदि एक condition बदल दें तो क्या होगा?”
- “क्या counter-example मिल सकता है?”

## 17. :icon-check: Evaluation और Assessment in Mathematics (मूल्यांकन)


### 17.1 Assessment for learning (अधिगम के लिए मूल्यांकन)

- Lesson के दौरान evidence collect करें।

### 17.2 Assessment of learning (अधिगम का मूल्यांकन)

Unit/term के अंत में achievement report करने वाला assessment; यह summative हो सकता है। केवल final score से learning process और misconception पूरी तरह नहीं दिखते।

### 17.3 Diagnostic assessment (निदानात्मक मूल्यांकन)

Specific gap identify करने के लिए:

- “तुमने denominator add क्यों किया?”
- “Graph में कौन-सा scale पढ़ा?”
- “क्या इसे counters/diagram से दिखा सकते हो?”
- “इस equation में दोनों sides equal क्यों हैं?”

### 17.4 Formal और informal tools

| Tool (उपकरण) | Mathematics evidence |
|---|---|
| Observation (अवलोकन) | Strategy, participation, tool use |
| Interview (साक्षात्कार) | “How did you get this?” से reasoning |
| Checklist (जाँच-सूची) | Construction/solution steps |
| Rubric (मापदंड-सारणी) | Concept, strategy, representation, reasoning, communication |
| Portfolio (कार्य-संग्रह) | Drafts, corrections, investigations और growth |
| Exit ticket (त्वरित जाँच) | Lesson के बाद immediate concept evidence |
| Project/investigation | Data collection, modelling, explanation |
| Peer/self-assessment | Reflection और criteria awareness |

### 17.5 Validity और reliability

- **Validity (वैधता):** assessment intended skill को measure करे। यदि mathematical reasoning चाहिए तो केवल handwriting/speed को measure करना valid नहीं।
- **Reliability (विश्वसनीयता):** comparable performances को consistent तरीके से score किया जाए। Clear criteria और rubric reliability improve करते हैं।
- Multiple evidence और accessible response modes fair picture देते हैं।

### 17.6 Good feedback

**Weak:** “गलत है।”

**Useful:** “तुमने length और breadth identify की हैं; अब देखें कि question boundary पूछ रहा है या inside covering। Unit भी check करो।”

### 17.7 Higher-order mathematics assessment

Remember → understand → apply → analyse → evaluate → create

Application और reasoning के लिए questions:

- “इस answer के दो possible methods दिखाओ।”
- “किसी गलत solution में error point खोजो।”
- “ऐसा rectangle बनाओ जिसका perimeter 20 हो और area maximum हो; explain करो।”
- “Graph की scale बदलने पर conclusion कैसे बदलेगा?”

## 18. :icon-warn: Problems of Teaching, Errors और Misconceptions (शिक्षण की समस्याएँ)

### 18.1 Common teaching problems

- केवल formula और algorithm पर निर्भरता;
- speed contests और public comparison;
- one-method classroom;
- language-heavy word problems बिना language support;
- manipulatives को decoration की तरह use करना;
- error को punishment या fixed ability label बनाना;
- real-life context को बिना quantities/assumptions के use करना;
- advanced learner को repetitive extra work देना;
- learner की strategy सुने बिना correction करना।

### 18.2 Error analysis

```figure
type: error-analysis-ctet
caption: wrong answer को learner की strategy और misconception के evidence की तरह पढ़ें
```

Error से संकेत मिल सकता है:

- place value या sign confusion;
- denominator/unit-part misconception;
- ratio में same-factor relation का gap;
- equation equality का unclear meaning;
- property/classification confusion;
- perimeter-area-volume mix-up;
- graph scale/key ignore करना;
- reading/language barrier;
- prerequisite gap या anxiety।

### 18.3 Diagnostic → remedial cycle

```text
Observe → Ask for reasoning → Identify pattern → Diagnose gap
→ Give matched representation/activity → Practise → Re-check transfer
```

**Remedial teaching (सुधारात्मक शिक्षण):**

- diagnosed need-specific हो;
- conceptually meaningful हो;
- same difficult worksheet की quantity न हो;
- concrete/visual/oral support दे;
- prompts धीरे fade करे;
- fresh but related task से re-assess करे।

### 18.4 Misconception–support table

| Child response | Possible misconception | Better support |
|---|---|---|
| `−5` को `−2` के right में रखना | Integer order/direction confusion | Number line movement |
| `1/3 > 1/2` | Denominator को whole-part size से नहीं जोड़ना | Equal fraction strips |
| `2:3` को `4:5` scale करना | Same factor भूलना | Unit strips/ratio table |
| `2x+3=11` में 3 केवल एक side से हटाना | Equality/balance unclear | Balance model |
| Every 4-sided shape square | Properties classify नहीं करना | Sort by sides/angles |
| Area = l+b | Covering और boundary mix | Unit squares + boundary tracing |
| Bar height = value | Scale/key ignore | Labelled graph read-aloud |
| `1 m²=100 cm²` | Squared conversion भूलना | Square grid model |
| Formula याद, context में apply नहीं | Relationship/units unclear | Varied examples and representations |

::: remember ✔ Teacher’s first question
“तुमने यह answer कैसे निकाला?” अक्सर “गलत क्यों किया?” से अधिक diagnostic और respectful है।
:::

## 19. :icon-book: Inclusive और Differentiated Mathematics Classroom (समावेशी और विभेदित कक्षा)

Inclusion का अर्थ सभी learners को same worksheet देना नहीं, बल्कि meaningful mathematical goal तक पहुँचने के लिए barriers हटाना है।

### 19.1 Multiple access और response modes

- tactile shapes और raised diagrams;
- large-print/grid paper और verbal description;
- audio/read-aloud या simplified language;
- counters, blocks, fraction strips और digital tools;
- oral explanation, drawing, table या written response;
- extra time और structured steps;
- bilingual glossary और peer support।

### 19.2 Accommodation vs modification

| Accommodation (अनुकूल व्यवस्था) | Modification (पाठ्यक्रम संशोधन) |
|---|---|
| Access/response mode बदलना | Goal, content या expected level बदलना |
| Extra time, reader, tactile model, oral response | अलग/कम learning outcome हो सकता है |
| Intended mathematical goal सामान्यतः same | Learning expectation बदल सकती है |

### 19.3 Differentiation

- Same concept, different entry points।
- Basic scaffold के साथ extension/proof task।
- Flexible groups based on current evidence, permanent labels नहीं।
- Advanced learner को depth, generalisation और investigation दें; केवल extra sums नहीं।
- Gender, language, caste, disability या income को mathematical ability का fixed indicator न मानें।

### 19.4 Mathematics anxiety

कम करें:

- low-stakes practice;
- think time;
- private feedback;
- multiple representations;
- errors पर respectful discussion;
- progress और strategy feedback;
- public speed ranking से बचाव।

### 19.5 Most appropriate inclusive response

यदि learner written task में कम score करता है पर oral reasoning strong है, तो intended skill के लिए multiple evidence लें। यदि language obstacle है, language scaffold दें लेकिन mathematical challenge unnecessarily lower न करें।

## 20. Most Appropriate Teacher Response (सबसे उपयुक्त शिक्षक प्रतिक्रिया)

| Remedial work के बाद progress unclear है | Fresh related task से transfer re-check करें |

Learner की method सुनो → representation से meaning स्पष्ट करो → reasoning/feedback दो → support fade करो → नई situation में re-check करो।

- [ ] Place value, rounding, number comparison और estimation clear हैं।

- [ ] Fractions: types, equivalence, comparison और operations revise किए।

- [ ] Ratio, proportion, unitary method और scale problems revise किए।
- [ ] Algebraic terms, like terms, expressions और equations clear हैं।
- [ ] Identities और patterns में generalisation समझते हैं।
