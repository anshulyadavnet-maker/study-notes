## Set 06 — भाषा-अधिगम और भाषा-अर्जन (Q101–Q120)

**Q101.** Language acquisition का सबसे उपयुक्त अर्थ क्या है?

- A. केवल grammar rules याद करना
- B. केवल examination में language लिखना
- C. meaningful interaction और exposure से भाषा का स्वाभाविक विकास
- D. केवल dictionary पढ़ना

**Answer:** C

**Explanation:** Acquisition interaction, exposure और communicative use से विकसित होने वाली प्रक्रिया है।

**Q102.** Language learning सामान्यतः किससे अधिक जुड़ा माना जाता है?

- A. planned instruction, practice और conscious understanding
- B. केवल natural imitation
- C. बिना context के बोलना
- D. केवल physical growth

**Answer:** A

**Explanation:** Learning में formal teaching, practice और conscious attention की भूमिका हो सकती है।

**Q103.** बच्चों की home language के बारे में सही pedagogical view क्या है?

- A. उसे classroom में रोकना चाहिए
- B. वह learning में हमेशा बाधा है
- C. उसे केवल घर तक सीमित रखना चाहिए
- D. वह prior knowledge और additional language learning का resource है

**Answer:** D

**Explanation:** Home language identity, meaning-making और school language के bridge के रूप में काम कर सकती है।

**Q104.** भाषा सीखने के लिए सबसे rich environment कौन-सा है?

- A. केवल silent copying
- B. meaningful listening, speaking, reading और writing opportunities
- C. केवल grammar worksheets
- D. केवल yearly examination

**Answer:** B

**Explanation:** भाषा skills communication और meaningful use से विकसित होती हैं।

**Q105.** Child language development में errors को teacher को कैसे देखना चाहिए?

- A. failure का permanent proof
- B. developing language system और learning process का evidence
- C. punishment का कारण
- D. intelligence की कमी

**Answer:** B

**Explanation:** Errors learner की current hypothesis और language understanding के संकेत दे सकती हैं।

**Q106.** Language teaching में “input” का अर्थ क्या है?

- A. learner का final exam
- B. केवल teacher marks
- C. केवल written homework
- D. learner द्वारा सुनी/पढ़ी गई meaningful language

**Answer:** D

**Explanation:** Comprehensible और meaningful language input acquisition को support करता है।

**Q107.** Language learning में interaction का महत्व क्या है?

- A. interaction meaning negotiation, feedback और practice का अवसर देती है
- B. interaction केवल discipline के लिए है
- C. interaction learning रोकती है
- D. interaction केवल older learners के लिए है

**Answer:** A

**Explanation:** बातचीत में learner language समझता, प्रयोग करता और feedback प्राप्त करता है।

**Q108.** बच्चों को भाषा सीखने के लिए केवल imitation पर निर्भर मानना—

- A. language learning की पूरी explanation है
- B. हमेशा सही है
- C. language की creative और rule-forming nature को ignore करता है
- D. grammar से जुड़ा नहीं

**Answer:** C

**Explanation:** बच्चे language patterns को समझकर नए sentences भी बनाते हैं।

**Q109.** भाषा का primary classroom purpose क्या है?

- A. केवल marks
- B. केवल spelling
- C. केवल handwriting
- D. विचार, भाव, अनुभव और information communicate करना

**Answer:** D

**Explanation:** Language communication और meaning-making का tool है।

**Q110.** Child-centred language teaching में learner—

- A. केवल teacher की lines repeat करता है
- B. language का meaningful use करता और अपने विचार express करता है
- C. केवल grammar definition याद करता है
- D. questions नहीं पूछता

**Answer:** B

**Explanation:** Learner participation, expression और communication language development के केन्द्र में हैं।

**Q111.** Story सुनाने के बाद children से predictions पूछना किसे support करता है?

- A. केवल handwriting
- B. केवल spelling
- C. listening comprehension और inferential thinking
- D. केवल memorisation

**Answer:** C

**Explanation:** Prediction सुनने, समझने और text से inference बनाने की क्षमता को बढ़ाती है।

**Q112.** Language acquisition में meaningful context क्यों आवश्यक है?

- A. context से words और structures का अर्थ स्पष्ट होता है
- B. context language को difficult बनाता है
- C. context केवल literature में होता है
- D. context grammar replace करता है

**Answer:** A

**Explanation:** Context language form को purpose और meaning से जोड़ता है।

**Q113.** भाषा सीखने में motivation बढ़ाने का तरीका कौन-सा है?

- A. केवल punishment
- B. learner की रुचि और वास्तविक communication needs से task जोड़ना
- C. केवल difficult dictation
- D. public comparison

**Answer:** B

**Explanation:** Relevant और meaningful tasks intrinsic participation बढ़ाते हैं।

**Q114.** Language class में learner autonomy का example क्या है?

- A. reading topic या response format में meaningful choice देना
- B. हर word teacher से पूछना
- C. केवल fixed answer
- D. questions रोकना

**Answer:** A

**Explanation:** Appropriate choice learner ownership और engagement बढ़ाती है।

**Q115.** “Language is a tool” statement का अर्थ क्या है?

- A. language केवल subject book है
- B. language केवल writing है
- C. language केवल grammar है
- D. language से व्यक्ति सोचता, समझता, interact और communicate करता है

**Answer:** D

**Explanation:** Language cognitive और social activity दोनों में tool की तरह काम करती है।

**Q116.** Primary learners को new vocabulary सिखाने का best तरीका?

- A. isolated list रटाना
- B. story, picture, action और repeated meaningful use
- C. केवल dictionary definition
- D. केवल spelling punishment

**Answer:** B

**Explanation:** Contextual exposure और repeated use word meaning तथा retention को support करते हैं।

**Q117.** Language learning में “comprehensible input” का अर्थ है—

- A. ऐसा language input जिसका कोई अर्थ न समझ आए
- B. केवल कठिन grammar
- C. learner level से थोड़ा चुनौतीपूर्ण लेकिन context/support से समझने योग्य input
- D. केवल translated words

**Answer:** C

**Explanation:** Understandable input acquisition और gradual development में मदद करता है।

**Q118.** Teacher child के incomplete sentence को meaning समझकर natural correct form में reply करता है। यह है—

- A. communicative feedback/modeling
- B. punishment
- C. assessment termination
- D. language restriction

**Answer:** A

**Explanation:** Meaningful response correct form का model देती है और communication जारी रखती है।

**Q119.** Language acquisition को support करने वाली classroom practice कौन-सी नहीं है?

- A. interaction
- B. meaningful reading
- C. केवल mechanical copying और silence
- D. storytelling

**Answer:** C

**Explanation:** केवल copying language use, comprehension और expression के पर्याप्त अवसर नहीं देती।

**Q120.** Language teaching में previous knowledge का उपयोग क्यों?

- A. learner responses को label करने के लिए
- B. new learning avoid करने के लिए
- C. केवल test बनाने के लिए
- D. new language forms को known experiences से connect करने के लिए

**Answer:** D

**Explanation:** Prior language और experience new learning का meaningful आधार बनते हैं।

## Set 07 — Listening, Speaking and Communication (Q121–Q140)

**Q121.** Listening skill develop करने का सबसे अच्छा तरीका क्या है?

- A. केवल spelling लिखवाना
- B. children को हमेशा silent रखना
- C. varied audio/speech सुनाकर gist, detail और inference questions पूछना
- D. केवल grammar rules

**Answer:** C

**Explanation:** Active listening में सुनना, समझना, select करना और respond करना शामिल है।

- B. केवल teacher talk
- C. केवल written test
- D. errors पर ridicule

**Answer:** A

**Explanation:** Speaking practice meaningful interaction और safe environment में बेहतर विकसित होती है।

**Q123.** Listening और hearing में अन्तर क्या है?

**Q126.** Discussion में केवल fluent children बोल रहे हैं। Teacher को—

**Q128.** Language communication में context का क्या महत्व है?
