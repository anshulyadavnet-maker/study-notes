### 1.1 घातांक के नियम (Laws of Exponents)

| नियम | सूत्र |
|---|---|
| गुणा | aᵐ × aⁿ = a^(m+n) |
| भाग | aᵐ ÷ aⁿ = a^(m–n) |
| घात की घात | (aᵐ)ⁿ = a^(mn) |
| शून्य घात | a⁰ = **1** (a ≠ 0) |
| ऋणात्मक घात | a⁻ⁿ = 1/aⁿ |
| भिन्नात्मक घात | a^(1/n) = ⁿ√a |
| गुणनफल | (ab)ᵐ = aᵐbᵐ |

**हल किया उदाहरण 1:** 2⁵ × 2³ ÷ 2⁶ = ?
→ 2^(5+3–6) = 2² = **4**

**हल किया उदाहरण 2:** यदि 3ˣ = 81 हो तो x = ?
→ 81 = 3⁴ → **x = 4**

**हल किया उदाहरण 3:** (16)^(3/4) = ?
→ 16 = 2⁴ → (2⁴)^(3/4) = 2³ = **8**

### 1.2 करणी (Surds)
- √a × √b = √(ab), √a ÷ √b = √(a/b)
- **हरात्मकरण (Rationalisation):** 1/(√3 + 1) → ऊपर-नीचे (√3 – 1) से गुणा → (√3 – 1)/2

**अनुमानित मान (याद रखें):** √2 ≈ 1.414 • √3 ≈ 1.732 • √5 ≈ 2.236 • √7 ≈ 2.646

## अध्याय 2 — बीजगणित की नींव (Foundation of Algebra)

### 2.1 शब्दावली

| शब्द | अर्थ | उदाहरण |
|---|---|---|
| चर (Variable) | बदलने वाली राशि | x, y, a |
| अचर (Constant) | निश्चित मान | 5, –7 |
| पद (Term) | + या – से अलग हिस्सा | 3x², –5y |
| गुणांक (Coefficient) | चर के साथ की संख्या | 3x² में 3 |
| समान पद (Like terms) | चर व घात समान | 4x और 7x |
| असमान पद | चर/घात अलग | 4x और 4x² |

**पदों की संख्या के आधार पर:**
- एकपदी (Monomial) — 5x
- द्विपदी (Binomial) — x + y
- त्रिपदी (Trinomial) — x² + 2x + 1
- बहुपद (Polynomial) — कई पद

**घात (Degree):** सबसे बड़ी घात। जैसे 3x³ + 2x – 5 → घात = **3**
- घात 1 = रैखिक (Linear), घात 2 = द्विघात (Quadratic), घात 3 = घन (Cubic)

### 2.2 संक्रियाएँ
- **जोड़/घटाव:** केवल **समान पद** ही जुड़ते हैं। 4x + 3x = 7x, पर 4x + 3y = 4x + 3y (जुड़ेंगे नहीं)
- **गुणा:** गुणांक × गुणांक, घात **जोड़ें**। 3x² × 4x³ = 12x⁵
- **भाग:** गुणांक ÷ गुणांक, घात **घटाएँ**। 12x⁵ ÷ 4x² = 3x³

## अध्याय 3 — बीजगणितीय सर्वसमिकाएँ (Identities) ⭐

> **यह अध्याय Junior level का सबसे ज्यादा scoring भाग है। सर्वसमिकाएँ रट लें।**

### 3.1 आधारभूत सर्वसमिकाएँ

```
1.  (a + b)²  = a² + 2ab + b²
2.  (a – b)²  = a² – 2ab + b²
3.  a² – b²   = (a + b)(a – b)
4.  (x + a)(x + b) = x² + (a + b)x + ab
5.  (a + b)³  = a³ + b³ + 3ab(a + b)
6.  (a – b)³  = a³ – b³ – 3ab(a – b)
7.  a³ + b³   = (a + b)(a² – ab + b²)
8.  a³ – b³   = (a – b)(a² + ab + b²)
9.  (a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
10. a³ + b³ + c³ – 3abc = (a+b+c)(a²+b²+c²–ab–bc–ca)
```

### 3.2 व्युत्पन्न (Derived) — परीक्षा में सीधे काम आते हैं

```
a² + b²   = (a + b)² – 2ab  =  (a – b)² + 2ab
(a + b)²  = (a – b)² + 4ab
(a – b)²  = (a + b)² – 4ab
यदि a + b + c = 0  →  a³ + b³ + c³ = 3abc
x² + 1/x² = (x + 1/x)² – 2  =  (x – 1/x)² + 2
x³ + 1/x³ = (x + 1/x)³ – 3(x + 1/x)
x⁴ + 1/x⁴ = (x² + 1/x²)² – 2
```

### 3.3 हल किए उदाहरण

**उदाहरण 1:** यदि a + b = 7 और ab = 12, तो a² + b² = ?
→ (a+b)² – 2ab = 49 – 24 = **25**

**उदाहरण 2:** यदि x + 1/x = 3, तो x² + 1/x² = ?
→ 3² – 2 = **7**
→ आगे: x³ + 1/x³ = 27 – 9 = **18**

**उदाहरण 3:** (102)² की गणना करें।
→ (100 + 2)² = 10000 + 400 + 4 = **10404**

**उदाहरण 4:** 97 × 103 = ?
→ (100 – 3)(100 + 3) = 10000 – 9 = **9991**

**उदाहरण 5:** यदि a – b = 5 और ab = 14, तो a + b = ?
→ (a+b)² = (a–b)² + 4ab = 25 + 56 = 81 → **a + b = 9**

**उदाहरण 6:** यदि a + b + c = 0, तो a³ + b³ + c³ = ?
→ **3abc**

## अध्याय 4 — गुणनखंडन (Factorisation)

### 4.1 चार मुख्य विधियाँ

**(i) उभयनिष्ठ गुणनखंड निकालना**
→ 6x² + 9x = 3x(2x + 3)

**(ii) पदों का समूहन (Grouping)**
→ ax + ay + bx + by = a(x+y) + b(x+y) = **(a+b)(x+y)**

**(iii) सर्वसमिका का प्रयोग**
→ x² – 16 = (x + 4)(x – 4)
→ x² + 6x + 9 = (x + 3)²

**(iv) मध्य पद का विभाजन (Splitting the middle term)** — सबसे जरूरी
→ **x² + 7x + 12**
  ऐसे दो अंक खोजें जिनका **गुणनफल = 12** और **योग = 7** → 3 और 4
  → x² + 3x + 4x + 12 = x(x+3) + 4(x+3) = **(x+3)(x+4)**

**उदाहरण:** x² – 5x + 6
→ गुणनफल 6, योग –5 → –2 और –3 → **(x–2)(x–3)**

**उदाहरण:** x² – x – 6
→ गुणनफल –6, योग –1 → –3 और +2 → **(x–3)(x+2)**

> 💡 **संकेत:** अचर पद **धनात्मक** हो → दोनों गुणनखंडों के चिह्न **समान** (मध्य पद जैसा)। अचर पद **ऋणात्मक** हो → चिह्न **विपरीत**।

## अध्याय 5 — रैखिक समीकरण (Linear Equations)

### 5.1 एक चर वाला
**नियम:** जो पक्ष बदले, चिह्न बदले। चर एक ओर, संख्याएँ दूसरी ओर।

**उदाहरण:** 3x + 5 = 20 → 3x = 15 → **x = 5**

**उदाहरण (भिन्न सहित):** (x/2) + (x/3) = 10
→ LCM 6 से गुणा: 3x + 2x = 60 → 5x = 60 → **x = 12**

### 5.2 दो चर वाले युगपत समीकरण (Simultaneous Equations)

**विधि 1 — विलोपन (Elimination):**
```
2x + 3y = 13   ...(i)
3x – y  = 3    ...(ii)
```
→ (ii) को 3 से गुणा: 9x – 3y = 9
→ (i) में जोड़ें: 11x = 22 → **x = 2**
→ (ii) में रखें: 6 – y = 3 → **y = 3**

**विधि 2 — प्रतिस्थापन (Substitution):** एक समीकरण से x का मान निकालकर दूसरे में रखें।

### 5.3 हलों की प्रकृति (Nature of Solutions)

a₁x + b₁y + c₁ = 0, a₂x + b₂y + c₂ = 0 के लिए:

| शर्त | हल | ग्राफ |
|---|---|---|
| a₁/a₂ ≠ b₁/b₂ | अद्वितीय हल (Unique) | प्रतिच्छेदी रेखाएँ |
| a₁/a₂ = b₁/b₂ ≠ c₁/c₂ | कोई हल नहीं | समांतर रेखाएँ |
| a₁/a₂ = b₁/b₂ = c₁/c₂ | अनंत हल | संपाती रेखाएँ |

### 5.4 शब्द-समस्या
**उदाहरण:** दो संख्याओं का योग 45 और अंतर 9 है। संख्याएँ?
→ x + y = 45, x – y = 9 → जोड़ें: 2x = 54 → x = 27, y = 18
→ **27 और 18**

## अध्याय 6 — द्विघात समीकरण (Quadratic Equations)

**मानक रूप:** ax² + bx + c = 0 (a ≠ 0)

### 6.1 श्रीधराचार्य सूत्र (Quadratic Formula)

> ### x = [–b ± √(b² – 4ac)] / 2a

### 6.2 विविक्तकर (Discriminant) D = b² – 4ac

| D का मान | मूलों की प्रकृति |
|---|---|
| D > 0 | दो भिन्न वास्तविक मूल |
| D = 0 | दो बराबर वास्तविक मूल |
| D < 0 | कोई वास्तविक मूल नहीं (काल्पनिक) |

### 6.3 मूलों के संबंध

> **मूलों का योग (α + β) = –b/a**
> **मूलों का गुणनफल (αβ) = c/a**
> **समीकरण बनाना:** x² – (योग)x + (गुणनफल) = 0

**हल किया उदाहरण 1:** x² – 5x + 6 = 0 हल करें।
→ गुणनखंड: (x–2)(x–3) = 0 → **x = 2 या 3**

**हल किया उदाहरण 2:** x² – 7x + 10 = 0 के मूलों का योग व गुणनफल?
→ योग = 7, गुणनफल = **10**

**हल किया उदाहरण 3:** यदि मूल 3 और –5 हों, तो समीकरण?
→ योग = –2, गुणनफल = –15
→ x² – (–2)x + (–15) = **x² + 2x – 15 = 0**

**हल किया उदाहरण 4:** k के किस मान के लिए x² + kx + 9 = 0 के मूल बराबर हैं?
→ D = 0 → k² – 36 = 0 → **k = ±6**

## अध्याय 7 — उन्नत प्रतिशत, लाभ-हानि व मिश्रण

### 7.1 उन्नत लाभ-हानि प्रश्न

**बेईमान दुकानदार (False Weight):**
> लाभ % = [त्रुटि / (सही भार – त्रुटि)] × 100

**उदाहरण:** एक दुकानदार 1 kg के बदले 900 g देता है। लाभ %?
→ त्रुटि = 100 → [100/(1000–100)] × 100 = 100/900 × 100 = **11⅑%**

**अंकित मूल्य + छूट का संयुक्त प्रश्न:**
**उदाहरण:** एक वस्तु का MP, CP से 40% अधिक है। 25% छूट देने पर लाभ %?
→ CP = 100 → MP = 140 → SP = 140 × 0.75 = 105
→ लाभ = **5%**

**बराबर SP पर एक लाभ एक हानि:**
> हानि % = (x²)/100, जहाँ x = समान प्रतिशत

### 7.2 मिश्रण व अनुपात (Alligation)

> ### सस्ते की मात्रा : महँगे की मात्रा = (महँगा – औसत) : (औसत – सस्ता)

**उदाहरण:** ₹30/kg और ₹40/kg की चाय को किस अनुपात में मिलाएँ कि मिश्रण ₹34/kg का हो?
→ (40 – 34) : (34 – 30) = 6 : 4 = **3 : 2**

**दूध-पानी का क्लासिक प्रश्न:**
**उदाहरण:** 60 लीटर मिश्रण में दूध व पानी 2 : 1 में हैं। कितना पानी मिलाएँ कि अनुपात 1 : 2 हो जाए?
→ दूध = 40 L, पानी = 20 L
→ दूध स्थिर (40 L) रहेगा। नया अनुपात 1:2 → पानी = 80 L
→ मिलाना होगा = 80 – 20 = **60 लीटर**

## अध्याय 8 — चक्रवृद्धि ब्याज (Compound Interest) ⭐

### 8.1 सूत्र

> ### A = P(1 + R/100)ᵀ
> ### CI = A – P

**अलग-अलग स्थितियाँ:**

| स्थिति | सूत्र |
|---|---|
| वार्षिक संयोजन | A = P(1 + R/100)ᵀ |
| अर्धवार्षिक (Half-yearly) | A = P(1 + R/200)²ᵀ |
| त्रैमासिक (Quarterly) | A = P(1 + R/400)⁴ᵀ |
| भिन्न-भिन्न दर | A = P(1+R₁/100)(1+R₂/100)... |

### 8.2 SI बनाम CI — महत्वपूर्ण अंतर

- **1 वर्ष के लिए SI = CI** (हमेशा)
- **2 वर्ष:** CI – SI = **P(R/100)²**
- **3 वर्ष:** CI – SI = **P(R/100)² × (300 + R)/100**

**हल किया उदाहरण 1:** ₹8000 पर 10% वार्षिक दर से 2 वर्ष का चक्रवृद्धि ब्याज?
→ A = 8000 × (1.1)² = 8000 × 1.21 = ₹9680
→ CI = **₹1680**
*(तुलना: SI = 1600, अंतर = 80 = 8000 × (10/100)² ✔)*

**हल किया उदाहरण 2:** किसी धन पर 2 वर्ष में SI ₹400 और CI ₹420 है। दर?
→ 1 वर्ष का SI = 200
→ अंतर 20 = 200 पर 1 वर्ष का ब्याज → R = (20/200) × 100 = **10%**
*(जाँच: P = 2000 → SI = 400 ✔, CI = 2000×1.1² – 2000 = 420 ✔)*

**हल किया उदाहरण 3:** कोई धन CI पर 2 वर्ष में दुगुना हो जाता है, तो 4 वर्ष में कितना गुना?
→ 2 वर्ष = 2 गुना → 4 वर्ष = 2 × 2 = **4 गुना**
> ⭐ **नियम:** CI पर n वर्ष में x गुना → mn वर्ष में **xᵐ गुना**

### 8.3 जनसंख्या व मूल्यह्रास
- **वृद्धि:** P(1 + R/100)ᵀ
- **ह्रास (Depreciation):** P(1 – R/100)ᵀ

## अध्याय 9 — साझेदारी (Partnership)

**सरल साझेदारी (समान समय):** लाभ का बँटवारा पूँजी के अनुपात में
→ A : B = पूँजी₁ : पूँजी₂

**चक्रवृद्धि साझेदारी (अलग समय):** लाभ का अनुपात = (पूँजी × समय) के अनुपात में

**हल किया उदाहरण:** A ने ₹5000 12 महीने के लिए, B ने ₹6000 8 महीने के लिए लगाए। ₹2100 लाभ का बँटवारा?
→ अनुपात = (5000×12) : (6000×8) = 60000 : 48000 = **5 : 4**
→ A = 2100 × 5/9 = **₹1166.67**, B = **₹933.33**

## अध्याय 10 — उन्नत समय-कार्य व पाइप

### 10.1 दक्षता (Efficiency) संबंध

> यदि A, B से **n गुना तेज़** है → समय का अनुपात A : B = **1 : n**

**उदाहरण:** A, B से दुगुना तेज़ है। दोनों मिलकर 12 दिन में काम करते हैं। A अकेला कितने दिन में?
→ दक्षता A : B = 2 : 1, कुल = 3
→ A अकेला = 12 × 3/2 = **18 दिन**

### 10.2 तीन व्यक्ति साथ
**सूत्र:** 1/T = 1/a + 1/b + 1/c

**उदाहरण:** A 10, B 15, C 30 दिन में। तीनों साथ?
→ LCM = 30 इकाई → क्षमताएँ 3, 2, 1 = 6/दिन → **5 दिन**

### 10.3 बीच में छोड़कर जाना
**उदाहरण:** A और B साथ 8 दिन में काम करते हैं। दोनों 4 दिन साथ काम करके A चला जाता है। B अकेला 20 दिन में पूरा काम करता है। शेष काम B कितने दिन में करेगा?
→ 4 दिन में काम हुआ = 4/8 = 1/2
→ शेष 1/2 काम B करेगा = 20 × 1/2 = **10 दिन**

### 10.4 पाइप व टंकी (Pipes & Cistern)
- भरने वाला पाइप = **+**, खाली करने वाला = **–**
- **उदाहरण:** A 12 घंटे में भरता, B 15 घंटे में भरता, C 20 घंटे में खाली करता। तीनों साथ?
→ LCM = 60 → 5 + 4 – 3 = 6/घंटा → **10 घंटे**

## अध्याय 11 — उन्नत चाल-समय-दूरी

### 11.1 रेलगाड़ी संबंधी

| स्थिति | दूरी |
|---|---|
| खंभा/व्यक्ति (स्थिर) पार करना | रेलगाड़ी की लंबाई |
| प्लेटफॉर्म/पुल पार करना | रेलगाड़ी + प्लेटफॉर्म |
| दो रेलगाड़ियाँ पार करना | दोनों की लंबाइयों का योग |

**सापेक्ष चाल (Relative Speed):**
- विपरीत दिशा → चालें **जोड़ें** (a + b)
- एक ही दिशा → चालें **घटाएँ** (a – b)

**हल किया उदाहरण:** 120 m और 180 m लंबी दो रेलगाड़ियाँ 40 km/h व 50 km/h से विपरीत दिशा में आ रही हैं। एक-दूसरे को पार करने में समय?
→ कुल दूरी = 300 m
→ सापेक्ष चाल = 90 km/h = 90 × 5/18 = 25 m/s
→ समय = 300/25 = **12 सेकंड**

### 11.2 नाव व धारा (Boat & Stream)

> **धारा के अनुकूल (Downstream) = u + v**
> **धारा के प्रतिकूल (Upstream) = u – v**
> **नाव की चाल u = (D + U)/2**
> **धारा की चाल v = (D – U)/2**

**हल किया उदाहरण:** एक नाव धारा के अनुकूल 16 km/h और प्रतिकूल 10 km/h चलती है। नाव व धारा की चाल?
→ नाव = (16+10)/2 = **13 km/h**
→ धारा = (16–10)/2 = **3 km/h**

## अध्याय 16 — सांख्यिकी व प्रायिकता

### 16.1 वर्गीकृत आँकड़ों का माध्य

### 16.4 प्रायिकता (Probability)

**आधार तथ्य:**

**हल किया उदाहरण 3:** दो सिक्के उछालने पर कम से कम एक चित आने की प्रायिकता?

### 16.5 आँकड़ों का चित्रीय निरूपण (Pictograph, Bar & Pie Chart) — नया

> 📌 आधिकारिक Junior सिलेबस: "पिक्टोग्राफ… पाई एवं दण्ड चार्ट, अवर्गीकृत आँकड़ों का चित्र • ग्राफ, दण्ड आरेख तथा मिश्रित दण्ड आरेख" — Set 1 ch 20.2 में एक-पंक्ति परिचय था; परीक्षा-स्तर के नियम यहाँ:

- **पिक्टोग्राफ (Pictograph):** एक चित्र/प्रतीक = निश्चित संख्या। जैसे 🍎 = 5 विद्यार्थी → 3 🍎 = 15।
- **दण्ड आरेख (Bar Graph):** दण्ड की **ऊँचाई = मान**; आधार समान। दो/अधिक श्रेणियों के लिए **मिश्रित दण्ड आरेख** (side-by-side bars)।
- **पाई चार्ट (Pie Chart):** पूरा वृत्त = 360° = 100% → **1% = 3.6°**। किसी भाग का कोण = (भाग/कुल) × 360°।
- **रेखा ग्राफ (Line Graph):** समय के साथ बदलाव (trend) दिखाने के लिए।

**हल किया उदाहरण:** 720 छात्रों के सर्वेक्षण में विज्ञान 180, गणित 240, अन्य 300 — पाई चार्ट में गणित का कोण?
→ (240/720) × 360° = **120°**  |  विज्ञान = 90°, अन्य = 150° (कुल 360 ✔)

> ⚡ **ट्रिक:** पाई चार्ट के प्रश्न में "कोण दिया हो, मान निकालना हो" → भाग = (कोण/360°) × कुल। "मान दिया, कोण चाहिए" → कोण = (मान/कुल) × 360°।

## अध्याय 18 — ज्यामितीय रचनाएँ व चतुर्भुज (Constructions & Quadrilaterals)

> 📌 **नया अध्याय (UPESSC Junior सिलेबस 2026):** "समान्तर रेखाएँ, **चतुर्भुज की रचनाएँ**, त्रिभुज" — रचना-आधारित प्रश्न MCQ में steps के क्रम/उपकरण के रूप में आते हैं।

### 20.1 रचना के उपकरण व नियम

- रचना (Construction) = केवल **रूलर (unmarked) + परकार** से सटीक चित्र बनाना; चाँदे/मापनी नहीं (परख में steps-क्रम पूछा जाता है)।
- आवश्यक रचनाएँ: कोण 60° व 90°, कोण-समद्विभाजक, लम्ब-समद्विभाजक, 30°/45° (60° या 90° के आधे से)।

| रचना | पहला कदम | कुंजी |
|---|---|---|
| कोण 60° | किरण पर परकार से चाप; वही त्रिज्या दूसरी बार | समबाहु त्रिभुज का कोण |
| कोण-समद्विभाजक | कोण के शीर्ष से चाप → दोनों भुजाओं पर बिंदु | दोनों बिंदुओं से समान चाप |
| लम्ब-समद्विभाजक | रेखा के दोनों सिरों से आधे से अधिक त्रिज्या के चाप | ऊपर-नीचे प्रतिच्छेद |
| त्रिभुज (3 भुजाएँ) | सबसे लंबी भुजा आधार; सिरों से अन्य दो त्रिज्याओं के चाप | SSS |

> ⚡ **TET का पसंदीदा प्रश्न:** "60° बनाने के लिए परकार की त्रिज्या कितनी रखें?" → कोई भी सुविधाजनक (same radius दो चाप)। "कोण-समद्विभाजक में कितने चाप?" → शीर्ष से 1 + प्रत्येक भुजा-बिंदु से 1 (कुल 3 चाप)।

### 20.2 चतुर्भुज (Quadrilateral) — ज़रूरी तथ्य

- चतुर्भुज के **चारों कोणों का योग = 360°**।
- **समान्तर चतुर्भुज (Parallelogram):** सम्मुख भुजाएँ समान्तर व बराबर; सम्मुख कोण बराबर; विकर्ण परस्पर समद्विभाजित करते हैं।
- **आयत (Rectangle):** समान्तर चतुर्भुज + सभी कोण 90°; विकर्ण बराबर।
- **समचतुर्भुज (Rhombus):** सभी भुजाएँ बराबर; विकर्ण 90° पर काटते हैं (पर बराबर नहीं)।
- **वर्ग (Square):** आयत + समचतुर्भुज — सब कुछ बराबर, विकर्ण 90° पर व बराबर।
- **समलम्ब (Trapezium):** केवल एक जोड़ी भुजाएँ समान्तर।
- **पतंग (Kite):** आसन्न भुजाओं के दो जोड़े बराबर; विकर्ण 90° पर।

> 💡 **तुलना:** वर्ग ⊂ आयत ⊂ समान्तर चतुर्भुज; वर्ग ⊂ समचतुर्भुज ⊂ समान्तर चतुर्भुज। ("वर्ग सबका बेटा" 😊)

**रचना-उदाहरण (समान्तर चतुर्भुज):** दो आसन्न भुजाएँ व अन्तर्गत कोण दिए हों → आधार भुजा बनाओ → दिए कोण पर दूसरी भुजा → दोनों सिरों से समान्तर रेखाएँ।

### 20.3 अभ्यास प्रश्न
1. चतुर्भुज के कोण 90°, 80°, 110° हैं — चौथा कोण? → 360 – 280 = **80°**
2. समचतुर्भुज के विकर्ण किस कोण पर काटते हैं? → **90°**
3. जिस चतुर्भुज में केवल एक जोड़ी भुजाएँ समान्तर हों? → **समलम्ब**
4. आयत के विकर्ण बराबर होते हैं — सही/गलत? → **सही**

## अध्याय 19 — त्रिकोणमिति का परिचय (Basic Trigonometry)

> 📌 **नया अध्याय (UPESSC Junior सिलेबस 2026):** आधिकारिक list में "…घातांक, **त्रिकोणमिति**" — बुनियादी अनुपात व कोण-तालिका यहाँ।

### 19.1 त्रिकोणमितीय अनुपात (समकोण त्रिभुज में)

समकोण त्रिभुज ABC (C = 90°, कर्ण = AB) में कोण A के लिए:

- **sin A = लम्ब/कर्ण** = BC/AB
- **cos A = आधार/कर्ण** = AC/AB
- **tan A = लम्ब/आधार** = BC/AC

> ⚡ **ट्रिक:** **PAP/BAH/POA** — sin = P/H, cos = B/H, tan = P/B ("Pandit Badri Prasad / Har Har Bole" जैसा ढंग से अपना तरीका बनाएँ)।
> **tan A = sin A / cos A**; **sin²A + cos²A = 1**; **sin(90° – A) = cos A**।

### 19.2 कोण-तालिका (रटें) — 0°, 30°, 45°, 60°, 90°

| अनुपात | 0° | 30° | 45° | 60° | 90° |
|---|---|---|---|---|---|
| sin | 0 | 1/2 | 1/√2 | √3/2 | 1 |
| cos | 1 | √3/2 | 1/√2 | 1/2 | 0 |
| tan | 0 | 1/√3 | 1 | √3 | ∞ (अपरिभाषित) |

> ⚡ **याद-ट्रिक (sin के लिए):** √0/2, √1/2, √2/2, √3/2, √4/2 = 0, 1/2, 1/√2, √3/2, 1 — और cos उल्टा क्रम।

**कुछ मान याद रखें:** sin 30° = 1/2 • cos 60° = 1/2 • tan 45° = 1 • sin 90° = 1 • cos 0° = 1

### 19.3 हल किए उदाहरण

**उदा 1:** sin 30° + cos 60° = ? → 1/2 + 1/2 = **1**
**उदा 2:** tan 45° × sin 90° = ? → 1 × 1 = **1**
**उदा 3:** sin²30° + cos²30° = ? → (1/2)² + (√3/2)² = 1/4 + 3/4 = **1** (सर्वसमिका ✔)

### 19.4 अभ्यास प्रश्न
1. sin 60° का मान? → **√3/2**
2. cos 0° + sin 90° = ? → **2**
3. tan 60° × cos 30° = ? → √3 × √3/2 = **3/2**
4. यदि sin A = 1/2 तो A = ? → **30°**
5. sin 30° × cos 60° + sin 60° × cos 30° = ? → (1/2×1/2) + (√3/2×√3/2) = 1/4 + 3/4 = **1**
